# Projeto 5: Homeland (Pátria para Pátria)

A página **Homeland** foi desenvolvida durante o Sprint 5 no programa de desenvolvimento web da TripleTen. O projeto foi construído a partir de um design no Figma e tem como objetivo oferecer uma experiência responsiva para três tamanhos de tela: **mobile (320px)**, **tablet (768px)** e **desktop (1280px)**.

Os *breakpoints* utilizados foram 544px e 1024px. A imagem principal foi implementada de forma que, abaixo de 1024px, sempre ocupe toda a largura da viewport, independentemente das bordas laterais da página. Isso foi feito usando as ferramentas 'calc()' e 'width: 100%'. Os arquivos e pastas do projeto foram organizados de forma minimalista e conforme a metodologia BEM.

## Recursos do projeto

- HTML5, CSS3
- Design responsivo
- Media queries
- Metodologia BEM
- Flexbox
- Figma
