# Projeto 5: Homeland (Pátria para Pátria)

A página Homeland foi desenvolvida durante o Sprint 5 no programa de desenvolvimento web da TripleTen. Esse projeto foi criado a partir de um design no Figma, com o objetivo de ser responsivo em 3 viewports distintos: mobile(320px), tablet(768px) e desktop(1280px). Os breakpoints foram definidos em 544px e 1024px. A imagem foi estruturada de forma que, abaixo da resolução 1024px, sempre ocupe o tamanho total da tela, independente das bordas laterais da página. Isso foi feito usando as ferramentas 'calc' e 'width: 100%'. Os arquivos e pastas do projeto foram organizados de forma minimalista e conforme a metodologia BEM.

## Recursos do projeto

- Figma
- Design responsivo (mobile, tablet, desktop)
- Breakpoints 544px e 1024px
